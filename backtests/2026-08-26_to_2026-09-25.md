## Caveats

- Gap uses Dhan's official daily open (pre-open price) vs previous close, for Nifty and stocks. The engine uses the first 3-min candle's open; for Nifty these can differ by ~0.2%.
- Dhan's 1-min equity data ends at the 15:14 bar, so 15:15 square-offs use the 15:14 close.
- If SL and target fall in the same 3-min bar, SL is assumed first (same as the engine).
- Stock universe is the current `config/nifty50.json`, not the index as it stood on each day.
- One month, 22 trades. Small sample.
